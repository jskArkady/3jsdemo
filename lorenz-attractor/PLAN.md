# 5. 로렌츠 혼돈 관측소

## 목표
- ../stem-demos/PLAN.md 준수. lorenz-attractor.html.
- 매우 가까운 초기값에서 출발한 두 결정론적 궤적의 차이를 3D 위상공간과 거리 그래프로 보여준다.

## 모델
- dx/dt=σ(y-x), dy/dt=x(ρ-z)-y, dz/dt=xy-βz. 기본 σ=10, ρ=28, β=8/3.
- 초기 A=(1,1,1), B=(1+ε,1,1), 기본 ε=1e-5. 상태는 JS double, 그리기 버퍼는 Float32 가능.
- 고정 h=0.005 이하 RK4, 배속은 단계 개수 조절. 두 궤적을 동일한 h와 같은 solver로 계산한다.
- 표시 시간은 무차원 모델 시간, 축 x/y/z는 위상공간 변수다. 실제 물체의 공간 궤도나 날씨 예보로 표현하지 않는다.
- 그래프 d(t)=||X_A-X_B|| 및 log10(d). 0이면 바닥 clipping 사실을 표시한다. 일시적 감소가 있어도 혼돈 설명과 모순으로 처리하지 않는다.
- Lyapunov 지수는 첫 버전에서 계산하지 않는다. 단순 거리 기울기를 정확한 최대 Lyapunov 지수라고 부르지 않는다.
- 프리셋: ρ=0.5 원점 수렴, ρ=10 비영 평형 수렴, ρ=28 혼돈. 주어진 초기조건에서 실제 수치로 확인한다.

## 화면
- 어두운 공간의 얇은 축·눈금, 청록/호박색 두 궤적, 현재 위치의 밝은 점, 최근 구간 밝기 변화.
- 두 궤적 동시 보기, 하나만 보기, 두 현재 점을 잇는 거리선. 프레이밍은 알려진 범위로 고정하거나 완만하게 조정해 카메라가 흔들리지 않게 한다.
- x/y/z 숫자, 현재 거리, ε, 모델 시간 표시. 긴 궤적은 ring buffer(예: 각 12000점 이하).
- ring wrap 시 마지막과 첫 점 사이에 가짜 선분이 생기지 않도록 LineSegments 또는 draw range 분할을 사용한다.

## 조작
- σ 5~20, ρ 0~50, β 1~4, ε 1e-8~1e-1(log slider). 실제 유한값 범위와 프리셋의 설명을 확인한다.
- 프리셋·파라미터 변경은 두 상태·시간·이력을 초기화한다. 변경을 즉시 계산에 적용할지 적용 버튼 방식인지 일관되게 한다.
- pause/reset/step/0.25·1·2배속, 궤적 길이, XY/XZ/YZ/사선 보기, 자동 카메라.
- reduced-motion에서는 자동 카메라 OFF, 필요하면 정지 시작으로 하고 재생 버튼 안내.

## 검증
1. 평형점 (0,0,0), ρ>1에서 (±sqrt(β(ρ-1)), ±sqrt(β(ρ-1)), ρ-1)의 도함수≈0 확인.
2. 같은 초기값(ε=0 테스트)의 두 상태가 모든 단계에서 일치함을 확인.
3. 짧은 모델 시간 T=1에서 h, h/2, h/4의 수렴 확인(RK4 정밀도 수준). 혼돈의 긴 시간 좌표를 서로 같아야 한다고 검증하지 않는다.
4. ρ=0.5 수렴, ρ=28 충분한 시간 유한값, 서로 다른 ε의 초기 거리 검사.
5. ring wrap 가짜 선분, 이력 메모리 상한, log(0), UI 최댓값, pause/배속/리셋을 검사.
6. 프레임률이 달라도 동일한 solver step 수에서 같은 상태인지 검증한다.
7. 실제 화면·콘솔과 VALIDATION.md에 실행 조건·오차·모델 가정을 기록.

## 조사
원래 Lorenz 1963 논문 또는 대학의 Lorenz system 강의 자료로 방정식·기본 파라미터를 확인하고 링크를 VALIDATION.md에 기록한다. 날씨 예측 정확도는 주장하지 않는다.
