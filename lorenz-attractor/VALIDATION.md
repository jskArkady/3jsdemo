최종 상태: **Verified** (2026-09-22, WSL2 Linux). 아래 검증 범위에 대한 판정이며 실제 하드웨어 전체나 장기 예측 정확도를 보장하지 않는다.

## 산출물과 등록 정보

- 진입점: `lorenz-attractor/lorenz-attractor.html`
- 갤러리 카드 설명: **아주 가까운 두 초기값이 만드는 로렌츠 궤적과 거리 그래프로 결정론적 혼돈을 관측합니다.**
- 추가 파일: `test-model.cjs`, `test-browser.cjs`, 이 문서. 기존 `PLAN.md`와 다른 데모/공통 파일은 변경하지 않았다.
- Three.js 0.183.0 단일 HTML/import map 및 기존 데모의 한국어 제어, 갤러리 링크, DPR 제한, RAF 수명 관리 패턴을 재사용했다. 새 런타임 의존성 없음.

## 실제 조작

재생/일시정지, 초기화, 정지 중 한 단계(h=0.005), 0.25/1/2배속, ρ=0.5/10/28 프리셋, σ=5~20·ρ=0~50·β=1~4·ε=10⁻⁸~10⁻¹ 슬라이더, 10/30/60 모델 시간 궤적 길이, A+B/A/B 보기, 선형 거리/log₁₀ 거리 그래프, XY/XZ/YZ/사선 시점, 자동 회전.

- 파라미터·프리셋 변경 시 시간·두 상태·이력을 즉시 초기화하며 재생/정지 상태는 유지한다. 프리셋은 σ=10, β=8/3을 복원하고 ε는 유지한다.
- 초기화 버튼은 현재 파라미터에서 다시 시작한다. 한 단계는 정지 상태에서만 가능하다.
- 일시정지는 계산과 자동 회전을 함께 정지한다. 자동 회전 기본값은 OFF. 마우스 이동으로 카메라는 움직이지 않는다.
- reduced-motion이면 정지 상태로 시작하며 실행 중 해당 설정을 켜도 계산·회전을 정지한다.
- 모바일 세로 및 가로에서는 문서 스크롤로 모든 제어에 접근한다. 데스크톱 제어 패널은 독립 스크롤한다.

## 모델과 가정

`dx/dt=σ(y−x)`, `dy/dt=x(ρ−z)−y`, `dz/dt=xy−βz`. 초기 A=(1,1,1), B=(1+ε,1,1), 기본 ε=10⁻⁵. 기본 σ=10, ρ=28, β=8/3.

방정식·고전 파라미터 근거: [University of Toronto, The Lorenz system — An introduction to chaos](https://www.math.toronto.edu/kzhang/teaching/courses/mat332-2022/_8-lorenz-system/).

모든 시간·좌표·거리는 무차원이다. 3D 위치는 `(x,z,y)`로 배치해 z를 수직으로 보이며 축은 원래 변수명으로 표시한다. 실제 공간 이동, 날씨 예측, Lyapunov 지수 계산을 주장하지 않는다. 거리가 일시적으로 감소할 수도 있다. log₁₀ 그래프는 d≤10⁻¹⁴를 −14에 표시한다. 선형 그래프는 현재 이력에 맞춰 수직 범위를 조절한다.

계산은 JS double/RK4 고정 h=0.005, 렌더 데이터만 Float32다. dt는 0.1초, 프레임 계산량은 40단계로 제한한다. 백그라운드 복귀 시 지난 시간을 따라잡지 않는다. 궤적은 각 상태 12,000점 이하, 그래프 이력은 601샘플(0.1 모델 시간 간격, 약 60시간)이다. 표시는 시간순 인접점 쌍의 LineSegments로 구성하므로 ring 시작/끝을 연결하지 않는다. 최근 구간이 더 밝다. 기본 화면은 사전 계산 없이 초기값부터 진행한다.

## 재실행

```sh

flock /tmp/threejs-stem-browser.lock node lorenz-attractor/test-browser.cjs

WSL 기존 Playwright `/home/bayta/.cache/ms-playwright-go/1.57.0/package`, Chromium `/snap/chromium/current/usr/lib/chromium-browser/chrome`, 기존 `/tmp/abyssal-fonts.conf`, SwiftShader를 사용했다. 전체 브라우저 수명 동안 공통 flock을 보유했다.

## 브라우저·화면 결과

- 실제 RAF 재생 및 pause/resume/reset/step 통과. 한 단계 시간 비교는 JS 부동소수점 연산을 고려해 10⁻¹² 허용오차 사용.
- 모든 프리셋, 모든 슬라이더 최댓값, 속도 선택, 두 그래프 모드, 궤적 선택/길이, 정지 중 자동 시점 변경 통과.
- 13,000단계 진행 후 실제 GPU 위치 버퍼와 시간순 모델 데이터를 비교: 12,000점, 23,998 vertices, Float32 최대 변환 오차 **1.90715×10⁻⁶** (<4×10⁻⁶). ring 경계의 가짜 연결 없음.
- 1440×1000, 390×844, 844×390에서 렌더·가로 overflow 없음·모든 컨트롤 스크롤 접근 검사 통과. `/tmp/lorenz-desktop.png`, `/tmp/lorenz-390.png`, `/tmp/lorenz-844.png` 캡처 생성 및 데스크톱/세로/가로 화면 직접 검토.
- reduced-motion 초기 정지·회전 OFF, 재생 버튼으로 시작 통과.
- visibilitychange와 BFCache persisted pagehide/pageshow **합성 이벤트**에서 중단/재개 통과. non-persisted pagehide에서 dispose 및 canvas 제거 통과.
- CDN 요청 차단과 WebGL 생성 실패를 주입한 별도 페이지에서 오류 안내 노출 통과.
- 정상 경로 콘솔/pageerror **0개**, WebGL context 정상, 렌더 호출 존재 확인. 실제 RAF와 수치 fast-forward를 분리했고 화면 FPS를 성능 벤치마크로 주장하지 않는다.

## 독립 리뷰 및 남은 제한

별도 Reviewer가 최초 요구·공통/개별 계획·실제 소스를 독립 검토했다. 발견한 “평면 보기에서 정지 중 자동 회전 선택 시 UI는 사선이지만 카메라는 미변경”을 `pose()` 호출로 수정했고 해당 브라우저 전이를 검증했다. 캡처 검토로 기본 사선 카메라 방향도 두 날개가 잘 보이도록 조정했다. 가로 모바일에서 제어 패널의 최소 높이가 만든 큰 여백은 단일 열 레이아웃으로 수정했다. 최종 독립 리뷰에서 수치 테스트를 재실행하고 보고된 오차 일치 및 수정 사항을 확인했으며 잔여 중대한 문제나 검증 과장을 발견하지 못했다.

미검증: 실제 브라우저 뒤로/앞으로 이동에 따른 BFCache 채택 여부, 실제 모바일 GPU/Safari/Firefox, 장시간 실시간 성능 및 메모리 프로파일, 전체 연속 파라미터 공간. 수명 경로는 합성 이벤트와 코드 검토로 확인했으며 GPU 자원 해제는 dispose 경로·컨텍스트 종료 호출·canvas 제거로 확인했다. 네트워크/CDN 의존은 기존 데모와 동일하다. 매우 작은 ε의 두 궤적은 Float32 렌더에서 겹쳐 보일 수 있으나 거리 계산은 double 상태를 사용한다. 연속계의 장시간 정확한 좌표/혼돈 지수는 검증 범위 밖이다.
