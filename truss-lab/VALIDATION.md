## 실제 기능·조작

- 구조 프리셋 3종, 하중 위치 0–8 m, 하향 하중 0–30 kN, E 70–210 GPa, A 200–1000 mm².
- 하중 이동 재생/일시정지, 0.5·1·2배속, 초기화. 최초 시작과 초기화는 정지 상태이다.
- 정지 중에도 수동 변경을 즉시 해석한다. 프리셋 변경은 하중·재료·이동 상태를 유지하고 부재 선택을 첫 부재로 초기화한다.
- 정면/사선/자동 카메라. 마우스 이동에는 반응하지 않는다. 일시정지는 하중과 자동 카메라를 함께 멈춘다. 자동 카메라를 끄면 하중은 계속 이동한다.
- 인장(민트)/압축(주황)/무축력(회색), 축력 kN 또는 응력 MPa 색상, 현재 최대 절댓값 범례.
- 부재 직접 클릭 또는 키보드로 선택 목록 조작. 선택 부재의 길이·부호·축력·응력·연신을 표시한다.
- 변형 배율 0–200×, 회색 원형, 절점 번호, 지점 기호, 반력 화살표, 총하중과 분배 절점하중 화살표.
- 최대변위 mm, 좌우 Ry kN, 왼쪽 Rx kN, 정규화 자유 DOF 잔차·전체 평형 오차.
- reduced-motion 기본 정지/자동 카메라 꺼짐, 실행 중 설정 변경 시 정지. 390×844 세로 화면은 페이지 스크롤, 844×390 가로 화면은 조작 패널 내부 스크롤로 모든 조작에 접근한다.
- 오류 발생 시 기존 해석 값·모형·화살표를 무효화한다. CDN/WebGL 초기화 실패와 WebGL context loss 안내, 종료 시 RAF·이벤트·ResizeObserver·geometry/material/renderer 정리.

## 모델과 단위

2D 핀 접합, 작은 변형, 선형 탄성, 축력만 전달. `b=[−c,−s,c,s]`, `ke=(EA/L)bᵀb`, 부분 피벗 가우스 소거로 자유 DOF를 푼다. 반력은 `Ku−F`의 구속 DOF, 축력은 `N=(EA/L)bu`, 응력은 `N/A`. 계산은 m/N/Pa/m², UI에서 GPa·mm²·kN·mm·MPa로 변환한다.

왼쪽 핀 ux=uy=0, 오른쪽 롤러 uy=0. E와 A는 전 부재에 균일하게 적용한다. 삼각형 프리셋은 하부 중앙 하중 절점을 연결한 수직재 포함 4절점/5부재, Warren 9절점/15부재, Pratt 8절점/13부재이며 모두 `m=2j−3`과 비특이 강성을 확인했다. 각 프리셋 경간 8 m, 높이 2 m.

하중은 인접 하부 절점에 선형 거리 비율로 분배하며 총힘·모멘트를 보존한다. 시간 적분/진동 해석이 아닌 정적 재해석의 연속 표시다. 이동 위치는 입력 슬라이더와 별도 실수 상태로 관리하여 반올림 누적을 방지한다. 실제 RAF delta를 0.05 s로 제한하고 숨김/복귀 시 지난 시간을 누적하지 않는다. 느린 기기에서는 표시 이동이 느려질 수 있다.

피벗 크기가 원래 행렬 최대 절댓값의 `10⁻¹²` 미만이면 특이/근특이 오류로 처리하며 대각 보정은 없다. 자유 DOF 잔차와 전체 평형 오차는 `10⁻⁸` 초과 시 결과를 무효화한다. 힘 기준은 `max(1 N, Σ|F|)`, 모멘트는 추가로 경간으로 나눠 정규화한다.

3D 두께·받침·바닥은 표시용이며 면외 강성·자중·굽힘을 포함하지 않는다. 실제 최대변위/경간 또는 부재 축변형률이 1% 초과이면 작은 변형 가정 경고를 표시한다. 강도·좌굴·피로·파괴·안전율은 계산하지 않는다.

계산식과 핀 접합/작은 변형 가정 확인 자료: [MIT, David Roylance, Trusses](https://ocw.mit.edu/courses/3-11-mechanics-of-materials-fall-1999/c41082eb8e8022644f8de9a9f6f91c2c_MIT3_11F99_truss.pdf), 특히 Deflections와 Matrix Analysis of Trusses. 별도 알고리즘을 복사한 테스트가 아니라 HTML의 `truss-core` 함수를 추출하여 검증한다.
