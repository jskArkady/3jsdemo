# 9. 트러스 하중 실험실

## 목표
- ../stem-demos/PLAN.md 준수. truss-lab.html.
- 절점하중이 지점 반력과 부재 인장/압축으로 전달되는 과정을 3D 전시와 정확한 2D 선형 해석으로 보여준다.

## 모델
- 2D pin-jointed truss, 절점당 ux/uy 2자유도, 부재는 축력만 전달, 작은 변형·선형 탄성. 자중은 첫 버전에서 무시.
- 부재 길이 L, c=dx/L, s=dy/L, 벡터 b=[-c,-s,c,s]. ke=(EA/L) bᵀb를 global DOF에 조립.
- 왼쪽 pin은 ux=uy=0, 오른쪽 roller는 uy=0. free DOF의 Kff uf=Ff를 pivot 있는 직접법 또는 SPD Cholesky로 풀고 잔차를 확인한다.
- 부재 연신 δ=b u_e, 축력 N=EA δ/L. N>0 인장, N<0 압축. 반력 R=Ku-F를 구속 DOF에서 구한다.
- 첫 버전은 안정한 미리 정의된 삼각형·Warren·Pratt 프리셋. 각 topology의 중복/누락 부재·지점 구속을 검증한다. 임의 구조 편집기는 범위 밖.
- 교량 폭을 가진 3D 모형은 동일 평면 트러스의 전시적 두께이며 out-of-plane stiffness를 계산하지 않는다. 장식 가새를 계산 부재처럼 오해하게 그리지 않는다.
- 이동 하중은 하부 chord의 인접 절점에 거리 비례로 분배하는 이상화된 deck 전달 모델. 절점 사이 한 부재의 중간 집중하중을 실제 truss bending으로 계산한 것처럼 표현하지 않는다.
- 기본 span 약 8 m, 높이 2 m, E=200 GPa, A=400 mm², 하중 10 kN. 단위 변환을 명확히 한다. 이는 예제 수치이며 허용 설계값이 아니다.

## 화면
- 정면 및 사선 3D 모형, 지점 기호와 반력 화살표, 이동 하중 화살표, 선택 부재 하이라이트.
- 인장/압축/0 force를 색과 범례·부호로 표시. 크기는 |N| 또는 |N/A| 중 선택한 물리량에 맞춰 범례를 변경한다.
- 변형 전 ghost와 과장 변형, 배율 표시. 작은 변위 선형 가정을 벗어나는 설정은 경고하거나 범위를 제한한다.
- 부재 선택 시 길이·축력·축응력·연신, 전체에서 최대변위와 지점 반력·평형 잔차 표시. 재료 강도/좌굴 없이 안전율·파괴 판정을 하지 않는다.

## 조작
- topology preset, 하중 위치·크기(0~30 kN), E 또는 재료 예시, A 200~1000 mm², 변형배율, 축력/응력 색상.
- 명시적 부재 클릭 또는 HTML 선택 목록. 키보드로 같은 정보 접근 가능.
- 정적 해석은 값 변경 시 다시 풀고 시간 적분을 하지 않는다. 선택적 '하중 이동 재생/정지'만 시간 애니메이션이며 동적 진동 해석이 아니라고 표시한다.
- 초기화, 정면/사선, 자동 카메라. 정지 상태에서도 수동 하중 위치 변경은 다시 해석한다.
- 특이/near-singular K를 감지하면 오류 상태와 기존 결과 무효화를 표시한다. 임의 작은 diagonal 값을 넣어 불안정 구조를 안정한 것처럼 숨기지 않는다.

## 검증
1. 단일 축부재의 축방향 u=FL/EA와 반력 확인(횡방향 DOF는 적절히 구속).
2. 대칭 삼각 트러스 정상 집중하중의 손계산 부재력·반력과 비교. 대칭 형상에서 반력과 변위 대칭성 확인.
3. global ΣFx, ΣFy, Σmoment=0과 free DOF residual의 하중 정규화 오차 목표 1e-8 이하.
4. 하중 2배→u/N/R 2배, E 또는 A 2배→u 절반. 부정정 preset에서는 서로 다른 부재 E/A 변경의 효과를 단순 일반화하지 않는다.
5. 이동 하중 분배의 총힘·모멘트 보존, 끝점 x=0/span, zero load=zero output.
6. rigid motion/singular 사례를 계산 단위 테스트에서 검출. 길이 0 방지.
7. 실제 UI preset/하중/선택/정지, 3D geometry와 결과 일치, 화면·콘솔 검증 후 VALIDATION.md 기록.
