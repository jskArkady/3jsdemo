## 구현

황동 받침대, 36:24:36 톱니 기어, 구동축, 여섯 행성(수성~토성), 달, 토성 고리, 눈금과 원형 전시실을 구성했다. 기어 쌍의 회전비는 반지름 및 톱니 수에 따라 1:-1.5:1이며, 실제 전체 기어열의 동역학을 재현하는 모델은 아니다.

일식 시연은 기존 공전 시계를 보존하고 지구와 달을 정렬한다. 태양·달의 월드 좌표와 반지름으로 그림자 원뿔을 계산해 지구 표면 셰이더에 반영한다. 복귀 시 원래 공전·자전·기어 위치와 카메라 모드로 돌아간다. 정지 중에는 시연 전환도 정지하며, 재생을 눌러 진행한다.

조작: 일시정지/재생, 0.25·1·2·4배속, 자동 카메라 토글, 전체 보기/기어 보기, 일식 시연/복귀, FPS 및 갤러리 링크. reduced-motion에서는 자동 카메라가 기본으로 꺼진다. 크기·거리·주기가 축약된 원리 모형이라는 안내를 표시한다.

## 한계와 남은 위험

- SwiftShader 기반 기능 검증이므로 실제 GPU·모바일 장치의 FPS나 발열을 보장하지 않는다. 테스트에서 시간을 직접 진행한 FPS 표시는 성능 측정으로 사용하지 않았다.
- 다른 브라우저와 실제 장치 검증은 수행하지 않았다. 실제 브라우저 BFCache 채택 여부와 강제 GPU 컨텍스트 손실은 환경별 추가 확인 대상이다.
- CDN 사용으로 최초 실행에 인터넷이 필요하다.
- 이 환경의 `.git`은 정상 Git 저장소로 접근되지 않아 Git diff를 사용할 수 없었다. 실제 생성 파일과 계획을 직접 대조했다.
