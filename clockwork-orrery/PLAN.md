# 태양계 기계식 천문대 구현 계획

## 목표와 범위
- 독립 실행 파일: `clockwork-orrery/clockwork-orrery.html`.
- Three.js 0.183.0과 기존 단일 HTML 구조를 유지한다. 절차적 형상·표면을 사용하고 외부 모델·이미지·새 패키지는 추가하지 않는다.
- 목표 경험: 어두운 원형 전시실 가운데 황동 태양계 모형이 공전하고, 구동축과 톱니가 연결되어 움직이며, 지구·달의 정렬로 일식을 시연한다.
- 행성 크기·거리·주기는 감상을 위해 축약한다. 실제 천체력이나 정확한 태양계 축척으로 오해하지 않게 표시한다. 완전한 기계 동역학 해석은 범위 밖이다.

## 구현 전 확인
- 저장소 지침·README와 기존 장면의 후처리, 절차적 재질, FPS, 카메라 및 수명 관리 패턴을 확인한다.
- 독립적으로 변경할 수 있는 최소 코드를 재사용한다. 기존 장면과 공용 구조를 리팩터링하지 않는다.
- WSL의 구문 검사와 브라우저 검증 수단을 확인한다.

## 장면과 미술
1. 황동·검은 금속·짙은 목재의 원형 받침대, 눈금 고리와 구동축으로 전시물의 실루엣을 만든다.
2. 중심 태양, 수성·금성·지구·화성·목성·토성의 6개 행성을 가독성 있게 배치한다. 토성 고리와 지구의 달을 포함한다. 축척은 연출용이다.
3. 행성별 궤도 고리와 지지대를 서로 구분하고 위에서만 보이는 평면 구성이 되지 않도록 높이와 재질을 조절한다.
4. 받침대 일부를 개방해 회전하는 구동 장치를 보여준다. 톱니와 연결축은 납득할 수 있는 위치에 배치한다.
5. 어두운 전시실, 따뜻한 국소 조명과 차가운 보조 조명으로 금속 윤곽을 살린다. 거울 같은 금속이 검게 사라지지 않도록 절차적 환경광 또는 적절한 조명 구성을 사용한다.

## 운동과 일식 시연
- 중심 group → 공전 pivot → 지지대와 행성 → 자전 및 달 pivot의 계층으로 운동 책임을 나눈다.
- 하나의 시뮬레이션 시계에 공전·자전·기어를 연결하고 배속과 pause/resume이 모든 관련 요소에 일관되게 적용되게 한다.
- 맞물리는 단순 기어 쌍은 톱니 수 비율에 따라 반대 방향으로 돌리고, 같은 축의 부품은 같은 각도로 움직인다. 복잡한 실제 기어열을 표방하지 않는다.
- 일식 시연 버튼: 현재 상태에서 시연 모드로 매끄럽게 전환하고 태양·달·지구를 정렬한다. 지구의 국소 그림자와 관찰에 유리한 카메라를 제공한다.
- 일식 그림자는 광원 shadow 또는 명시적인 기하 기반 셰이더로 표현한다. 임의의 화면 덮개로 일식처럼 꾸미지 않는다. 태양의 발광 재질 자체가 그림자를 만들지 않는 점을 고려한다.
- 시연 종료/복귀 시 시간·카메라·일시정지 상태가 꼬이지 않도록 상태 전이를 명확하게 구현한다.
- 실제 천문 계산이 아닌 원리 시연이라는 안내를 표시한다.

## 카메라·UI·접근성
- 자동 카메라는 전체 전시물을 천천히 둘러보고 기계 하부와 행성 고리를 보여준다. 마우스 이동에 반응하지 않는다.
- 한국어 설명, 일시정지/재생, 배속, 자동 카메라 토글, 전체 보기/기어 보기, 일식 시연·복귀, FPS 및 갤러리 링크를 제공한다.
- 키보드 접근, label, 현재 상태 표시, 모바일 레이아웃, reduced-motion 기본 정지 카메라를 지원한다.
- DPR 상한, geometry/material 재사용, 톱니 인스턴싱 등을 적용하되 과도한 복잡성은 피한다.
- resize, 백그라운드 복귀 시간 점프, WebGL 초기화 실패, 이벤트 및 GPU 자원 정리를 처리한다.

## 단계별 검증과 완료 조건
1. 첫 화면에서 황동 기계식 태양계 모형을 명확히 읽을 수 있고 행성·고리·지지대가 심하게 충돌하지 않아야 한다.
2. 공전·기어 방향·배속·정지와 재개를 확인한다. pause 이후 시간이 갑자기 건너뛰지 않아야 한다.
3. 일식 시연 진입·종료와 반복 진입, 시연 중 pause와 배속 변경을 확인한다. 그림자가 실제 정렬에 대응해야 한다.
4. 구문 검사, 로컬 HTTP와 링크, 가능한 브라우저 콘솔·스크린샷·조작 검증을 실행한다. 데스크톱/모바일/reduced-motion을 확인한다.
5. 실제 diff와 최초 요청을 기준으로 최종 리뷰한다. 측정하지 않은 FPS나 검증하지 않은 브라우저 동작을 성공이라고 보고하지 않는다.
