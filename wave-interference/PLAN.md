# 2. 파동 간섭 수조

## 목표
- ../stem-demos/PLAN.md 준수. wave-interference.html만의 독립 데모와 VALIDATION.md.
- 두 파원의 중첩과 위상차를 입체 수면·평면 색지도·측정 그래프로 연결한다.

## 모델
- 선형 소진폭 수면 변위의 교육용 처방장. h(x,z,t)=Σ A_i g(r_i) cos(k r_i-θ_i(t)+φ_i), k=2πf/c, θ_i는 시간 적분한 위상.
- c는 일정한 모델 파속(기본 1 m/s), f 기본 1 Hz, 소스 위치 x=±1.2 m, 수조 약 8×6 m. A 기본 0.05 m.
- g(r)는 중심에서 유한한 완만한 방사 감쇠, 예: 1/sqrt(1+r/r0). 이는 시각화를 위한 이상화이며 실제 수심·분산·유체 해석이 아니다.
- 파원을 각각 켜고 끌 수 있고 기본 주파수는 공유한다. 위상차와 간격이 주 실험 변수다. 첫 버전에서 서로 다른 주파수 및 맥놀이는 필수가 아니다.
- 별도 강도 지도는 정현파의 시간 평균 h²: (a1²+a2²+2a1a2 cos(k(r1-r2)+φ1-φ2))/2. 순간 변위 지도와 범례를 구분한다.
- 측정 함수와 GPU 수면 shader가 같은 정의·파라미터를 사용하도록 검증한다. 중심 특이점·NaN이 없어야 한다.
- 주파수 변화는 누적 위상으로 시간 연속성을 유지한다. t*f를 바로 바꿔 파형이 튀는 구현을 피한다.

## 화면
- 어두운 실험대 위 얇은 투명 수조, 두 발진기와 구분 색, 수면 wire/solid 전환, 절제된 조명.
- 사선 입체 보기와 정확한 상부 보기. 위상이 다르더라도 같은 변위는 같은 색을 사용한다.
- 파장 눈금, 두 소스로부터 측정점까지 거리 선, 경로차와 현재 변위를 표시한다.
- 측정 그래프: h1, h2, 합 h. 그래프는 8~12초 길이 제한. 강도 선택 시 변위 그래프와 물리량 혼동 방지.

## 조작
- 공유 주파수 0.3~2 Hz, 위상차 -180~180°, 파원 간격 0.4~4 m, 진폭 0~0.1 m. 최대 주파수에서도 격자 해상도로 파장을 표현할 수 있게 한다.
- 측정점은 UI 좌표 또는 명시적 수면 클릭으로 이동한다. 클릭은 raycast 수평 기준면에 적용하고 카메라와 충돌하지 않게 한다.
- 프리셋: 동상 두 파원, 역상 두 파원, 단일 파원, 간격 확대.
- pause/reset/step/배속, 입체/상부, 순간 변위/평균 강도, 소스 토글. reset은 기록·위상·측정점을 명시적으로 초기화한다.

## 단계와 완료 검증
1. CPU의 파동·강도 함수를 작성하고 단위·특수값 테스트.
2. 수면 mesh(예: 160×120부터), shader와 측정값을 연결.
3. 상부/입체, 탐침, 그래프·프리셋 구현 후 모바일 화면 확인.
4. 동상·등거리 점의 합=2배, 역상·등거리 점의 합=0(오차 1e-9 수준 CPU), 파원 OFF=0, t와 t+1/f의 동일 상태 검사.
5. 강도 공식을 한 주기의 수치 평균 h²와 비교(상대 오차 목표 1e-4).
6. CPU/셰이더 수식 대조, 측정점 경계 및 소스 중심 유한값, 위상 wrap, pause 및 주파수 변경 검증.
7. 실제 RAF와 화면·콘솔 검증, VALIDATION.md에 모델 가정과 결과 기록.
