- 진입 파일: `wave-interference/wave-interference.html`
- 갤러리 카드 설명: 두 파원의 보강·상쇄를 입체 수면, 평균 강도 지도와 탐침 파형으로 비교하는 간섭 실험.
- 변경 범위: 이 폴더만. 공통 메뉴·README·다른 데모는 수정하지 않음.

## 구현 및 조작

단일 HTML에 CSS, CPU 계산, GLSL 수면, 상태·UI·수명 관리 포함. 기존 데모의 import map, 고정 카메라 보기, 반투명 패널, AbortController 이벤트 정리 패턴을 재사용했다. 새 런타임 의존성·이미지·모델 없음.

- 일시정지/재생, 정지 중 1/60 s 진행, 초기화, 0.25/1/2/4배속.
- 입체/정확한 상부 보기, 순간 변위/평균 강도, 격자/솔리드.
- 동상·역상·단일 파원·간격 확대 프리셋.
- 공유 주파수 0.3–2 Hz, 위상차 −180–180°, 간격 0.4–4 m, 진폭 0–0.1 m, 개별 파원 ON/OFF.
- 탐침 x∈[−4,4] m, z∈[−3,3] m 슬라이더. 두 파원 거리선·수평 경로차·변위·평균 제곱 변위·파장 눈금.
- 그래프는 항상 h₁/h₂/합 h [m], 최근 10초·최대 1201 표본. 강도 지도와 구별한다.
- 매개변수·탐침 변경은 시간/누적 위상을 유지하고 그래프를 비운다. 주파수 변경 시 k=2πf/c가 즉시 달라져 공간 무늬는 재조정된다. 누적 위상을 t×f로 재계산하지 않는다.
- 초기화/프리셋은 시간·위상·탐침·설정·보기·배속·기록을 초기화한다. reduced-motion이면 정지, 아니면 재생한다.
- 카메라 자동 이동 없음. reduced-motion 초기 정지 및 동적 변경 시 정지. 좁은 화면은 세로 스크롤, 데스크톱 패널은 내부 스크롤.

## 모델과 한계

`hᵢ = Aᵢ / √(1+rᵢ/0.5 m) × cos(2πfrᵢ/c − θ + φᵢ)`이고 `h=h₁+h₂`, `c=1 m/s`, `φ₁=0`, `φ₂=위상차`이다. 평균 강도 표시는 `⟨h²⟩=(a₁²+a₂²+2a₁a₂ cos(k(r₁−r₂)−φ₂))/2` [m²]. 물리적 에너지 유속 [W/m²]을 계산하지 않는다. 색 강도 지도는 제곱근 대비 변환, 범례는 0–0.020 m²이다.

선형·비분산 교육용 처방장으로 Navier–Stokes, 수심, 파원 시작 과도현상, 파면 인과 전파, 반사·회절을 풀지 않는다. 수조 테두리는 반사 경계가 아니다. 주파수 변경을 공간 전체에 즉시 반영하는 모형이다. 이 한계는 실제 수조 유체 해석으로 해석하면 안 된다.

수면 높이 6배 확대, x/z 길이는 m. CPU와 GLSL은 같은 감쇠·위상 부호·상수를 사용한다. 격자 160×120, 간격 0.05 m → 최소 파장 0.5 m당 10개 간격. 셰이더 색은 픽셀에서 직접 필드를 평가한다. 수면 모양만 격자 사이를 선형 보간한다.

고정 DT=1/120 s로 위상을 적분한다. 처방장의 위상 적분이므로 PDE CFL 조건은 해당하지 않는다. 프레임 dt≤0.05 s, 최대 24 substep, 배속은 단계 수에 적용. 느린 렌더링에서는 시뮬레이션 시간이 실제 시간보다 느려질 수 있다. 숨김/복귀에서 누적 시간을 버리고 따라잡지 않는다.

근거: [OpenStax 파동 중첩](https://openstax.org/books/university-physics-volume-1/pages/16-5-interference-of-waves), [Feynman Lectures, Interference](https://www.feynmanlectures.caltech.edu/I_29.html). 중첩과 시간 평균 제곱의 관계를 확인했고 방사 감쇠는 이 데모의 명시적 이상화이다.

## 실제 검증

WSL2 Node v24.16.0. 수치 테스트는 HTML의 `wave-model` 스크립트를 그대로 추출하여 실행한다. 복사한 별도 모델을 검증하지 않는다. module 스크립트 구문도 검사한다.

```sh
node wave-interference/model-test.cjs
flock /tmp/threejs-stem-browser.lock node wave-interference/browser-test.cjs
```

VM 모듈이 비활성화되어 있으면 검증기가 `--experimental-vm-modules`를 추가해 한 번 재실행합니다. 기존 Node 옵션과 스크립트 인자를 유지하며, 자식 검증기의 종료 코드를 반환합니다. 프로세스 시작 오류나 시그널 종료도 실패로 처리합니다.

GPU 검증은 렌더러에서 실제 사용한 `fieldGLSL`을 1×1 float render target으로 실행하고 `readRenderTargetPixels`로 읽었다. f={0.3,1,2}, φ={−180,0,127}, 파원 활성 3조합, 위치 5조합. 초기 1e−6 기준은 GPU 삼각함수/단정밀도 차이로 실패했으며, 최종 기준은 표시용 GPU 값의 절대 3e−5로 명시했다. CPU 수치 정확도 기준은 완화하지 않았다.
