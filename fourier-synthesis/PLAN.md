# 3. 푸리에 합성 조각

## 목표
- ../stem-demos/PLAN.md 준수. fourier-synthesis.html.
- 회전 벡터의 합이 폐곡선을 복원하는 과정을 주파수 성분·오차와 연결한다.

## 수학 모델
- 평면의 N개 균등 매개변수 표본을 복소수 z_n=x_n+i y_n로 표현. DFT C_k=(1/N)Σ z_n exp(-i2πkn/N).
- 역합성 z(t)=Σ C_k exp(i2πkt), t∈[0,1). k>N/2는 음수 주파수 k-N으로 표시한다. 짝수 N의 Nyquist를 중복하지 않는다.
- 기본 N=128 또는 256. 사용자가 그린 곡선은 호 길이 기준 균등 재표본화, 중심 이동, 일관된 표시 축척 적용. 전처리 전후 정의를 표시한다.
- 낮은 |k| 순서로 성분 수를 늘리는 방식을 기본으로 한다. 추가 진폭순 모드는 있으면 합성 포함 집합과 표시 순서를 명확히 구분한다.
- DC 성분·정규화·허수부 부호를 정확히 처리한다. 좌표계 화면 y반전이 수식까지 뒤집지 않게 한다.
- 오차는 원본 표본점 대비 RMSE로 계산하고 단위는 정규화 좌표임을 명시한다. 모든 성분 사용 시 표본에서 복원된다; 점 사이 보간이 원본 펜 궤적과 완전히 같다고 주장하지 않는다.

## 화면
- 중앙 복소평면 위 원·회전 화살표 연쇄와 합성 궤적. 원본 곡선은 희미하게 겹쳐 비교한다.
- 옆 또는 하단에 양·음 주파수의 진폭 막대와 선택 성분의 위상 표시. N, 사용 성분 수, RMSE, 주기를 표시한다.
- 기본 2D 복소평면의 사선 보기. 별도 시간축 펼침 보기에서는 세 번째 축을 시간으로 명확하게 표시하고 합성 평면과 혼동하지 않는다.
- 원은 공유 geometry, 벡터는 line buffer, 궤적은 bounded buffer. 성분마다 발광등을 만들지 않는다.

## 조작·입력
- 원/사각형/별/비대칭 폐곡선 프리셋, 성분 수 1~N, 주기·배속, 원/벡터/원본 토글, 평면/시간축 보기.
- 작은 2D 입력 pad에서 pointer로 그리기, 지우기, 적용. 최소 표본수·길이 검사, pointer capture/cancel, 끝점을 닫는 정책과 '폐곡선으로 연결' 안내.
- 동일 점만 입력한 경우 오류 안내 후 기존 유효 곡선을 유지한다. 과도한 입력 점수는 제한한다.
- 키보드 사용자를 위해 프리셋만으로 모든 핵심 학습을 할 수 있게 한다.
- pause/reset/한 단계, 자동 카메라(기본 평면 고정), 0.25/1/2배속. 곡선 변경 시 DFT·궤적·시간·오차를 함께 갱신한다.

## 검증
1. 상수 입력의 DC만 존재, 단일 복소 원 입력의 지정 k 한 성분, 실수 cosine의 ±k 켤레 관계 확인.
2. 전체 계수 역변환의 최대오차 <1e-9(정규화 좌표), Parseval Σ|z|²/N=Σ|C|² 확인.
3. 오차 곡선을 실제 채택한 성분으로 계산한다. 에너지 기반 RMSE 감소 관계와 단일 성분 복원 검사.
4. 균등 재표본화의 점 수·중복 끝점·짧은 세그먼트·폐곡선 wrap 확인.
5. 실제 UI로 preset, draw/apply/reset, 성분 수 1/N, pause/resume, 모바일 pointer 동작, 콘솔·스크린샷 확인.
6. VALIDATION.md에 수치 오차와 실제 실행한 입력 검증을 기록.
