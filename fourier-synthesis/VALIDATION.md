# 푸리에 합성 조각 검증

최종 상태: **Verified** (2026-09-22, WSL2 Linux). 아래 브라우저 재검증 결과를 포함하며, 실제 장치/BFCache의 미검증 범위는 별도 명시한다.

## 산출물과 사용법

- 진입점: `fourier-synthesis/fourier-synthesis.html`
- 갤러리 카드 설명: **회전 벡터를 더해 원·별·직접 그린 폐곡선을 복원하고, 주파수 성분과 복원 오차를 비교합니다.**
- `test-model.cjs`: HTML에 실제 포함된 순수 계산 스크립트를 추출하여 VM에서 실행한다. 별개 구현을 시험하지 않는다.
- `test-browser.cjs`: 기존 WSL Playwright/Chromium을 사용한다. 임의 포트 로컬 HTTP 서버와 브라우저를 테스트 종료 시 닫는다.
- 스크린샷: `desktop-plane.png`, `desktop-time.png`, `mobile-390.png`, `mobile-844.png`.
- 루트 메뉴, README 및 다른 데모는 수정하지 않았다. 단일 HTML과 기존 Three.js 0.183.0 CDN import map을 사용하며 새 런타임 의존성은 없다.

조작: 원/사각형/별/비대칭 프리셋, 1~128개 성분, 주파수 선택과 위상 읽기, 재생/일시정지, 현재 곡선 초기화, 정지 후 1/128 주기 진행, 4/8/16초 주기, 0.25/1/2배속, 원/벡터/원본 표시, 복소평면/시간축 보기, 자동 카메라, 입력 패드 드래그/지우기/적용, 갤러리 복귀. 작은 화면에서는 문서를 세로로 스크롤한다. 키보드 사용자는 프리셋으로 모든 핵심 학습을 할 수 있다.

## 모델과 단위

N=128, z=x+iy, 순변환에 1/N, 역합성에 양수 지수를 사용한다. 낮은 |k| 순서 `0,+1,-1,...,+63,-63,+64`로 포함 집합과 벡터 표시 순서를 동일하게 유지한다. Nyquist +64는 한 번만 포함하며 DC도 성분 수에 포함한다. 스펙트럼은 k=-63~+64를 보여준다. 진폭이 1e-10 미만이면 위상은 미정으로 표시한다.

입력은 2,048점으로 제한한다. 같은 점/너무 짧은 곡선은 거부하며 기존 곡선을 보존한다. 시작·끝을 직선으로 닫고 호 길이로 재표본화한 뒤 표본 평균을 빼고 최대 반지름으로 두 축을 동일하게 나눈다. 패드의 CSS 픽셀 좌표에도 두 축에 동일한 축척을 적용한다. y는 화면에서 위로 증가하도록 한 번만 반전한다.

RMSE는 전처리한 128개 복소 표본과 **현재 포함한 성분의 실제 역합성값**으로 계산한다. 모든 성분 사용 시 이 표본을 복원하며 점 사이의 원래 펜 궤적까지 같음을 보장하지 않는다. 시간축 보기의 세 번째 축은 `z=4t−2`로 표시한 정규화 주기 t이고 물리적 길이가 아니다. 회전 연쇄는 현재 t 평면에 놓인다. 민트 궤적은 1,025개 고정 평가점 중 현재 t까지 표시하며, 한 주기마다 다시 그린다.

ODE 적분을 사용하지 않는다. 회전은 닫힌 수식으로 평가하고 위상 시계만 고정 1/120초로 진행한다. 프레임 경과 시간은 최대 0.05초, 2배속에서도 프레임당 최대 12회 처리한다. 백그라운드 복귀 시 시계 기준과 잔여 시간을 지워 따라잡기를 방지한다. 곡선·성분 변경은 t/궤적/RMSE를 함께 재시작하고, 주기·배속 변경은 t를 유지한다. 보기 변경도 t를 유지한다.

수식 규약 확인: [NumPy 공식 DFT 설명](https://numpy.org/doc/2.2/reference/routines.fft.html)의 부호, 주파수 순서, `norm="forward"`에 해당하는 정규화. NumPy 자체는 구현 의존성으로 사용하지 않는다.

## 실행한 검증

```sh
node fourier-synthesis/test-model.cjs
flock /tmp/threejs-stem-browser.lock node fourier-synthesis/test-browser.cjs
```

초기 브라우저 실행은 샌드박스의 localhost listen EPERM으로 차단되었다. 이후 승인된 실행 환경에서 같은 명령으로 로컬 서버와 Chromium을 실행했다. 다른 작업 브라우저와의 경합은 전체 수명의 flock으로 방지했다.

HTML의 실제 두 실행 스크립트를 `/tmp/fourier-syntax-{0,1}.mjs`로 추출해 `node --check`를 실행했고 브라우저 테스트 스크립트 구문 검사도 통과했다. 단일 HTML 저장소이므로 별도 빌드/타입 체크/린터 설정은 없다.

### 수치 결과: PASS

허용오차 1e-9 (정규화 좌표/에너지). 원·사각형·별·비대칭 곡선 네 가지 모두에서 성분 수 1~128 전체를 순회했다.

| 항목 | 실측 최대 절대오차 |
| --- | ---: |
| 전체 계수 복원, 표본별 복소 거리 | 1.3867569994447829e-14 |
| Parseval 에너지 차이 | 9.992007221626409e-16 |
| RMSE²와 제외 성분 에너지 합의 차이 | 1.1102230246251565e-15 |
| 단일 복소 원의 비대상 계수 누출 | 8.477974542447323e-15 |

상수 DC, 음수/양수 원 k=-63,-7,1,19,64, 각 단일 성분 복원, 실수 cosine의 ±5 켤레, Nyquist 유일성, 성분 추가에 따른 RMSE 비증가, 재표본화 점 수/폐곡선 wrap/중복 끝점 제거/짧은 세그먼트/동일 점·짧은 곡선·NaN 거부, 중심 및 반지름 정규화도 통과했다.

### 브라우저 결과: PASS

실제 파일을 수정 없이 HTTP로 제공하며 실제 RAF를 실행했다. 일부 시계 경계 테스트만 `advance()`를 직접 호출했고 그 결과로 FPS 성능을 주장하지 않는다. Chromium은 WSL headless SwiftShader이며 DPR 상한은 1.75이다.

- 실제 재생 위상 증가, pause 시 위상·자동 카메라 동결, resume, 자동 카메라 끄기와 마우스 이동 무반응.
- reset/한 단계, 네 프리셋, 성분 1과 128 및 전체 복원 RMSE, 선택 주파수, 세 표시 토글.
- 4초/2배속 시계와 큰 프레임 경과 시간 제한, 평면/시간축 보기.
- 드래그 적용, 빈 입력 거부 및 기존 유효 모델 유지, 모바일 마우스 입력과 CDP 실제 터치 입력, pointercancel 처리.
- 1440×1000, 390×844, 844×390에서 실제 렌더와 스크린샷. 가로 넘침 없음, 주요 컨트롤은 세로 스크롤 후 뷰포트 안에 위치함.
- reduced-motion 변경 및 초기 로드 시 정지·자동 카메라 해제.
- visibilitychange 합성 이벤트에서 accumulator 제거. persisted pagehide/pageshow 합성 이벤트에서 RAF 정지/복귀. 일반 pagehide에서 dispose 및 GPU geometry 0 확인.
- CDN 요청 차단 시 안내, webglcontextlost 합성 이벤트 시 안내 및 dispose.
- 정상 페이지 콘솔 오류/미처리 오류 0. 마지막 렌더 진단: geometry 7개, draw call 21개, context lost=false (기본 15개 성분 상태).

## 독립 리뷰와 수정

Reviewer가 실제 계획과 소스를 읽기 전용으로 검토했다. 입력 패드 폭/높이별 개별 정규화가 모양을 왜곡하는 P2를 발견했다. 두 축에 동일 CSS 길이를 사용하도록 수정하고 패드 표시에도 역변환을 적용했다. Reviewer가 수정과 새 회귀 테스트를 다시 읽어 해결을 확인했다. 브라우저 회귀는 화면상 반지름 40px 원을 그린 뒤 실제 전처리 표본의 가로/세로 비율이 1±0.01인지 검사했다. 수정 후 전체 브라우저 테스트 재실행 PASS, 실측 비율 1.000000 (비율 오차 0)이었다.

## 미검증 범위와 남은 위험

- 실제 Safari/Firefox, 실제 모바일 하드웨어/GPU, 실제 스크린리더 음성 출력은 실행하지 않았다. HTML label, focus 표시, 상태 안내와 키보드용 프리셋을 제공한다.
- BFCache는 합성 lifecycle 이벤트를 통한 경로 검사이며 실제 브라우저 히스토리 캐시 진입/퇴출 검증은 아니다. visibility와 WebGL 중단도 합성 이벤트 기반이다.
- CDN 네트워크와 WebGL이 필요하다. 실패 안내는 검증했지만 오프라인 실행 기능은 범위 밖이다.
- 임의 자가교차 곡선, 극단적으로 빠른 손 움직임, 모든 주기·배속 조합의 장시간 소크 테스트는 수행하지 않았다. 입력 상한과 고정 버퍼로 메모리 증가는 제한한다.
- 그래프 점 사이와 곡선 모서리 부근에는 유한 Fourier 성분에 따른 진동/보간 차이가 존재한다. 이것을 정확한 원본 펜 궤적으로 해석하지 않는다.
