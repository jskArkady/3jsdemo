# 4. 선형변환 공간 실험실

## 목표
- ../stem-demos/PLAN.md 준수. linear-transform.html.
- 3×3 실수 행렬이 기저·격자·구·부피에 미치는 영향을 같은 화면에서 설명한다.

## 수학·정의
- 열벡터 convention y=A x를 명시. 편집 UI의 행/열, Three.js Matrix3.set 및 내부 column-major 배열을 혼동하지 않는다.
- 원점 고정의 선형변환만 다룬다. 평행이동·투영 카메라 변환을 섞지 않는다.
- det(A)는 유향 부피 배율, |det(A)|는 단위 정육면체 부피 배율. 음수는 방향 반전, 0은 차원 축소다.
- 특이값은 AᵀA의 대칭 고유값 제곱근. 작은 음수 roundoff만 허용오차 내 0으로 처리한다. 주축·특이값으로 단위구→타원체를 설명한다.
- 일반 행렬의 고유벡터는 복소수일 수 있다. 첫 버전은 **대칭 행렬에서만 실수 고유벡터 표시**를 지원한다. 그 외에는 '이 보기의 고유벡터 표시는 대칭 행렬에서 지원'이라고 명확하게 표시하며 임의 실수 축을 그리지 않는다.
- 대칭 3×3 Jacobi eigensolver를 작은 순수 함수로 구현. 근접·중복 고유값은 방향이 유일하지 않음을 표시한다.
- I→A 보간 A(u)=(1-u)I+uA는 교육용 행렬 보간임을 표시한다. 순수 회전 경로가 아니며 중간에 특이행렬이 될 수 있다. 수치와 기하 모두 같은 현재 A(u)를 사용한다.

## 화면과 조작
- 원본 단위구·큐브·격자를 ghost로, 변환 결과를 청록으로 표시. x/y/z 기저는 라벨·색으로 구분한다.
- 3×3 값 편집(-3~3 등 제한), 적용 버튼, 원본↔변환 진행 슬라이더, 재생/정지·초기화.
- 프리셋: 항등, 축별 확대, xy 전단, z축 45도 회전, 반사, 평면 투영, 대칭 결합 변환.
- 입력은 유한수 검사, 빈칸/NaN 시 기존 행렬 유지 및 오류 안내. 적용 때만 계산을 바꿔 편집 중간 상태를 렌더링하지 않는다.
- 표시 토글: 격자/구/큐브/기저/대칭 고유축/특이값 주축. 정면/상부/사선 보기와 자동 카메라.
- det, rank(상대 허용오차 정의), 특이값, 부피비를 표시. rank 결론은 값의 크기 대비 허용오차와 함께 문서화한다.
- singular matrix도 화면이 깨지지 않게 처리한다. 역행렬을 요구하지 않는 방식으로 점·선을 변환한다. 찌그러진 mesh 법선에서 NaN이 생기면 선·점 표시로 보완한다.

## 구현·검증
1. matrix apply/det/transpose product/Jacobi/SVD 수치 함수를 실제 UI와 공유.
2. 변환 전후 지오메트리와 범례, 편집 패널·보간·프리셋 연결.
3. I·대각·shear·반사·rank2·zero matrix에서 변환좌표/det/rank 확인.
4. 회전의 AᵀA≈I, det=1, 모든 singular value=1 확인.
5. 대칭 eigen 잔차·직교성, AᵀA 잔차 목표 정규화 1e-9, 특이값 곱≈|det| 확인.
6. 보간 중간의 표시값/실제 변형 일치, 비대칭 고유축 비활성화, 특이값 0, 중복 고유값 처리 확인.
7. 입력 오류, 모바일 표 편집, pause와 슬라이더, reduced-motion, 화면·콘솔 검증을 기록.
