핵심 원리

선형변환은 벡터의 덧셈과 상수배를 보존합니다. 따라서 세 기저 벡터가 어디로 이동하는지만 알면 공간의 모든 점이 어디로 가는지 정해집니다. 열벡터 규약에서는 행렬의 각 열이 변환된 x·y·z 기저입니다.

수식과 기호

y = Ax A(v+w) = Av+Aw · A(cv) = cAv 부피 배율 = |det A|

A는 3×3 행렬, x·y는 변환 전후 좌표입니다. det는 방향 부호를 포함한 부피 배율, rank는 변환 뒤 남는 독립 방향의 수입니다. 특이값 σ는 단위구가 변한 타원체의 주축 반길이이며 모두 0 이상입니다.

직접 관찰하기

  1. ‘축별 확대’에서 격자·기저·단위구가 함께 변하는지 확인하세요. 직접 대각행렬 diag(2,1,1)을 적용하면 부피비는 2가 됩니다.
  2. ‘xy 평면 투영’에서 구가 납작해지고 det가 0, rank가 2가 되는지 확인하세요.
  3. ‘x축 반사’의 음수 det와 ‘대칭 결합’의 고유축을 비교하세요. 보간 슬라이더를 옮기며 중간 행렬도 관찰하세요.

결과를 읽는 법

고유벡터 v는 Av = λv를 만족하는 0이 아닌 벡터입니다. 같은 직선 위에 남지만 λ가 음수면 방향이 뒤집힙니다. 특이값은 길이 배율이고 고유값과 일반적으로 다릅니다. det가 0이면 3차원 부피를 잃는 방향이 있습니다.

모델의 한계

이 데모의 고유축 표시는 대칭 행렬에서만 지원합니다. 원본과 목표 사이의 A(u)=(1−u)I+uA는 행렬 원소 보간으로, 회전 프리셋도 중간 과정은 순수 회전이 아닐 수 있습니다. 좌표와 배율은 무차원입니다.

상태

현재 A(u) · 허용오차와 모델
모든 길이와 부피비는 무차원입니다. 구 반지름 1, 큐브 [0,1]³. rank는 σ > 10⁻⁷ σmax인 개수(영행렬은 0). 고유축은 단위 방향이며 길이가 고유값은 아닙니다. 주축 반길이는 σ, σ=0의 축은 점으로 붕괴합니다. 특이값·고유값이 중복되면 축 방향은 유일하지 않습니다.
