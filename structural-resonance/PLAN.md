# 1. 구조물 공진 실험실

## 목표와 산출물
- 공통 지침 ../stem-demos/PLAN.md를 먼저 읽는다.
- 진입 파일 structural-resonance.html. 두 건물의 진동을 비교하고 공진·감쇠·진동 모드를 설명한다.
- 이 작업만 공통 index.html, README.md 통합까지 담당한다. 다른 데모 소스는 수정하지 않는다.

## 모델과 계산
- 4층 전단 건물 2개, 각 층에 수평 자유도 1개. 강체 바닥·선형 층간 스프링·점성 감쇠, 작은 변위 가정.
- M=diag(m_i). 각 층 스프링 k_i가 아래층과 해당층 사이 상대변위에 작용하도록 K를 조립한다. 1층 아래는 지반이다.
- 상대변위 q에 대해 M q'' + C q' + K q = -M 1 a_g(t). 기본 지반변위 y_g=A sin(ωt)이면 a_g=-Aω² sin(ωt)로 일관되게 계산한다.
- 기본값 제안: 층 질량 1000 kg, 층 강성 100000 N/m, 가진 진폭 0.01 m. 조작 범위는 수치 검증 후 제한한다. UI 단위는 kg, kN/m, Hz, mm.
- 대칭 행렬 M^-1/2 K M^-1/2를 Jacobi 등 작은 대칭 고유값 알고리즘으로 풀고 모드 및 고유진동수를 계산한다. 일반 비대칭 행렬 solver를 새로 만들지 않는다.
- 비교 A는 작은 양의 감쇠비(기본 0.01), B는 사용자가 정하는 감쇠비(기본 0.12). 양의 반정부호 C를 modal damping으로 구성하거나 근거 있는 Rayleigh damping을 사용한다. UI는 실제 적용된 정의를 표시한다.
- 자유진동: 초기 최상층 변위 후 외력 0. 강제진동: 지반 가진. 모드 보기: 계산된 고유벡터의 정현 운동을 '모드 형상'으로 별도 표시해 실제 강제응답과 구분한다.
- 고정 substep RK4 또는 검증된 선형계 적분법. 최대 허용 고유진동수에서 안정성을 검증한다. 처음에는 1/480 s 이하를 검토한다.
- 정상상태 응답 곡선을 제공할 경우 모드별 주파수 응답식을 사용하고, 과도응답을 정상상태 곡선으로 부르지 않는다. 무감쇠 공진은 무한대를 클리핑해서 숨기지 말고 별도 표기한다.

## 화면
- 진동대 위 나란한 두 4층 골조, 중립색 바닥·황동/청록 구분, 각 층의 실제 계산 변위로 기둥 끝점을 연결한다.
- 정지 위치 ghost와 현재 변형을 겹치고 변형 배율을 표시한다. 두 건물에 같은 배율을 적용한다.
- 하단 그래프: 최상층 상대변위 A/B와 지반 입력. 숫자: 선택 고유진동수·최대 층간변위·시뮬레이션 시간.
- 층간 변위를 응력이나 붕괴 확률로 표현하지 않는다. 별도 설계 평가 기능은 범위 밖이다.

## 조작과 실험
- 자유/강제/모드 선택, 주파수 0.1~5 Hz(검증 후 조정), 진폭 0~20 mm, 비교 B 감쇠비 0~0.3, 균일 질량·강성, 최상층 질량 비율 0.5~2.
- 프리셋: 공진 근처, 공진 밖, 감쇠 비교, 1~4차 모드. 실제 계산된 고유진동수에 맞춰 preset을 설정한다.
- 재생/정지, 초기화, 한 단계, 0.25/1/2배속, 정면/사선, 자동 카메라.
- 질량·강성·모드 변경은 상태와 이력을 재시작하고 알린다. 주파수·감쇠 변경은 정책을 명시한다. 파형 위상 불연속과 갑작스러운 큰 입력을 피한다.

## 구현 순서와 검증
1. M/K/모드/적분을 계산 함수로 작성하고 수치 검증을 먼저 수행한다.
2. 두 프레임 모델과 변형·정지 위치, 그래프·조작을 연결한다.
3. 프리셋·reduced-motion·자원 정리를 적용하고 실제 화면을 검토한다.
4. 1자유도 시험에서 f=sqrt(k/m)/(2π), 정적 F/k, 감쇠 자유진동 해와 비교한다.
5. 4층 모드 잔차 ||Kφ-λMφ||의 정규화 값과 질량 직교성을 검증한다(목표 1e-8 이하, 실제 오차 기록).
6. 무감쇠·무외력 에너지의 단기 상대 drift 목표 0.1% 이내, 감쇠 에너지 감소, h와 h/2 수렴 확인.
7. pause/step/speed/reset, A/B 감쇠 차이, 모드 변경, 최대 입력 장시간 유한값을 확인한다.
8. 자기 데모 완료 후 TASKS.md의 다른 8작업 결과를 모아 공통 등록·링크 검증을 수행한다.
