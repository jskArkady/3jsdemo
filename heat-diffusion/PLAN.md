# 8. 열전도 단면 실험실

## 목표
- ../stem-demos/PLAN.md 준수. heat-diffusion.html.
- 3D 블록 내부 온도를 이동하는 단면으로 관찰하고 열확산·경계조건·시간에 따른 평형을 이해한다.

## 모델
- 균질·등방성 직육면체, ∂T/∂t=α∇²T+s, α=k/(ρc_p) [m²/s], s는 체적 가열률을 온도 변화율 K/s로 변환한 값.
- 작은 3D cell-centered grid(예: 24×16×16). 물리 크기 약 0.12×0.08×0.08 m. x/y/z spacing 정의를 명확히 한다.
- 중심차분 Laplacian + explicit Euler를 쓸 경우 α dt(1/dx²+1/dy²+1/dz²)≤1/2 조건과 안전계수(예: 0.8)를 지킨다. 재료 변경 때 dt 재계산.
- 단열 Neumann 0-flux 경계는 대칭 face flux 방식으로 총 열을 보존한다. 고정온도 Dirichlet 경계는 외부 열저장고로 열이 출입하는 모델이다. 경계 셀 중심과 경계면 거리 차이를 일관되게 처리한다.
- 첫 버전은 한 블록 전체가 같은 재료다. 복합재·공간별 k는 제외한다. 재료 preset의 k,ρ,c_p,α는 실제 신뢰 자료를 확인하거나 명시적인 예시 값으로 표기한다.
- 실험: 중앙 hot spot의 단열 확산, 한쪽 뜨겁고 반대쪽 차가운 고정온도, 중앙 체적 가열 ON/OFF. 나머지 면 경계조건을 UI에 표시한다.
- °C로 표시해도 온도차 단위 K와 동일함을 적용. 내부 에너지 비교는 일관된 기준온도를 두고 ρc_p VΣ(T-Tref)로 계산한다.

## 화면
- 바깥 wireframe 블록과 온도 색 표면, X/Y/Z 절단면. 투명 voxel 전체를 겹치기보다 선택 단면·외면으로 내부를 읽게 한다.
- 고정 온도 범례(예: 20~100°C)와 수치, 범위 밖 값은 색 clipping 사실을 표시. 자동 범례면 변화를 인지할 수 있게 축 갱신을 표시한다.
- 탐침 위치·온도, 최솟값/최댓값/평균, 물리 시간. 탐침 시간 그래프와 중앙 단면 온도 곡선.
- 열원은 아이콘·영역으로 표시하고 계산 셀의 위치와 일치시킨다. 보기 단면 이동은 물리 상태를 바꾸지 않는다.

## 조작
- 실험 preset, 재료/α, 경계 온도, 열원 세기·ON/OFF, X/Y/Z 단면 및 위치, 탐침 좌표.
- pause/reset/한 수치 step/시뮬레이션 배속, 정면/사선/자동 카메라. 가속된 물리 시간 배율과 현재 dt를 설명에서 볼 수 있게 한다.
- 재료·경계 프리셋 변경은 재시작. 가열 toggle은 현재 상태 유지. 해상도 변경은 첫 버전 UI에 필요 없다.

## 검증
1. 균일 온도+단열+열원 OFF 상태가 그대로 유지.
2. 단열 확산에서 총 에너지의 상대 drift 목표 1e-9~1e-6(실측과 기준 기록), 평균 보존.
3. 무열원·안정 dt에서 새로운 극값이 생기지 않는 최대 원리 검사.
4. 한쪽 hot/반대 cold/측면 단열의 정상상태가 1차원 선형 온도 분포에 접근. 경계 cell 위치를 고려해 비교.
5. heat source ON의 에너지 증가가 주입량×시간과 맞는지 검사. Dirichlet 경우 보존을 기대하지 않는다.
6. 작은 격자와 dt/2 수렴, α 배율에 따른 시간척도 변화, 최대 배속에서 안정 조건 유지 확인.
7. 단면 축·probe index·범례, pause/step/reset, 모바일 화면, 실제 렌더·콘솔 검증 기록.
