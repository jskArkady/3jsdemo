# 6. 전자기 유도 발전기

## 목표
- ../stem-demos/PLAN.md 준수. electromagnetic-induction.html.
- 균일 자기장 속 회전 코일의 자세→자기선속→유도전압→전류 관계를 연결한다.

## 모델
- 이상적인 균일 B 속 면적 A의 N회전 코일. θ는 B와 코일 법선 사이 각도.
- 1회전 선속 Φ=BA cosθ [Wb], 선속쇄교 λ=NΦ [Wb-turn], 유도기전력 e=-dλ/dt=N B A ω sinθ [V].
- 일정한 순저항 부하 R>0에서 i=e/R [A]. 자기 인덕턴스, 접점 손실, 전기자 반작용과 역학적 속도 저하는 제외한다. 회전 속도는 외부 구동으로 유지한다.
- θ를 누적 위상으로 적분한다. rpm→ω=2π rpm/60. 역회전은 ω 부호를 바꾸고 θ를 연속으로 유지한다.
- 극성 반전은 B 부호 반전. B/N/A를 UI로 순간 변경하는 것은 실험 재설정이며 그 순간의 임펄스 유도전압은 모델링하지 않는다고 설명하고 기록을 초기화한다.
- 코일 기준 방향·법선 화살표·전류 양의 방향을 명시. 코일 회전 행렬과 cosθ 계산이 같은 정의를 사용해야 한다.

## 화면
- 두 자극 사이의 회전 직사각 코일, 축과 외부 구동부, 슬립링을 단순화한 연결과 저항 부하.
- 자기장은 균일 화살표와 흐린 선으로 표시한다. 움직이는 입자처럼 자기장 자체가 흐른다고 표현하지 않는다.
- 코일의 법선 화살표, θ 호, 관통 투영면적을 선택 표시. 실제 장선 계산이나 완전한 전자기장 solver가 아님을 명시한다.
- Φ, e, i 시간 그래프와 0선, 위상 차, 현재 전압·전류·주파수 수치를 표시.
- 전류 방향은 느린 방향 표식으로 표현하고 전자 드리프트 속도를 실제 전류와 같은 축척으로 주장하지 않는다. 밝기는 i²R에 따른 정규화 연출임을 설명한다.

## 조작
- rpm -120~120, B 0~1 T, N 1~100, A 0.01~0.1 m², R 10~100 Ω. 범위는 기본 보기 가독성에 맞게 제한 가능.
- 프리셋: 정지, 저속, 두 배 회전속도, 역회전, 두 배 권선. 비교할 때 축 범위를 고정할 수 있게 한다.
- pause/reset/step/배속, 극성 반전, 정면/측면/사선, 자동 카메라, 법선·장선 토글.
- 권선 N은 표시 geometry 개수와 1:1일 필요 없으며 '권선 형상 축약'을 명시한다. 파라미터 변경은 렌더와 수식을 함께 갱신한다.

## 검증
1. θ=0/π에서 e=0, θ=π/2에서 |e|=NBA|ω|, ω=0 또는 B=0에서 e=i=0.
2. λ의 중앙차분 시간미분과 -e를 비교(오차 목표 1e-5 상대 수준, dt 기록).
3. N/B/A/ω 2배에서 peak voltage 2배, R 2배에서 전류 절반, 역회전·극성 반전 부호 확인.
4. 전류·전압 평균은 한 주기 0, e_rms=peak/sqrt(2). i=e/R와 i²R 계산 확인.
5. 렌더된 법선 dot(B 방향)=cosθ 확인. 표시 축·단위·양의 방향의 일관성을 리뷰.
6. pause 중 회전 정지, 0rpm, 반전 반복, 파라미터 재설정, 화면·콘솔 검증을 기록.
